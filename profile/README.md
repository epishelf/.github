# epishelf

**Fast, portable tooling for robot-learning data**, from how media is stored to how a trainer reads it.

| Project | |
|---|---|
| [**blobpack**](https://github.com/epishelf/blobpack) | Pack dataset media into plain zip shards and read them fast, anywhere. Home of the [BRCD layout](https://github.com/epishelf/blobpack/blob/main/SPEC.md#blob-referenced-columnar-dataset-brcd-layout) for blob-referenced columnar datasets. |
| [**MediaRef**](https://github.com/epishelf/MediaRef) | Point at any media frame with nothing but `(uri, pts_ns)`. |
| [**tensorcodec**](https://github.com/epishelf/tensorcodec) | TorchCodec-compatible video decoding into NumPy. No PyTorch, no PyAV. |
